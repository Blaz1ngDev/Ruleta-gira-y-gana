# 🎁 Ruleta Interactiva "Gira y Gana"

Prototipo de aplicación web interactiva desarrollada para simular dinámicas de gamificación y sorteos de premios en negocios locales. El diseño está completamente optimizado para dispositivos móviles y computadoras.

## 🛠️ Tecnologías Utilizadas
* **HTML5:** Estructuración semántica y uso de la API de Canvas.
* **CSS3:** Animaciones, gradientes radiales y diseño responsivo (Media Queries).
* **JavaScript (Vanilla):** Lógica del sistema, manejo del DOM y síntesis de audio.

## 🌟 Características Clave
* **Animaciones con Canvas:** El renderizado de la ruleta y los giros se calculan dinámicamente mediante código mediante `requestAnimationFrame`.
* **Audio Sintetizado:** Integración de `AudioContext` para generar sonidos de clic analógicos en tiempo real sin cargar archivos pesados.
* **Control de Intentos:** Bloqueo de seguridad utilizando `localStorage` para evitar que un mismo usuario juegue más de una vez por día.
* **Acceso de Administrador:** Panel secreto protegido por eventos de teclado (Escribe "admin" para desbloquear el editor de premios).
